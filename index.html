      One page for DC’s other movie theaters

      What this is

      Washington has a handful of independent, nonprofit and museum screens showing old movies, second-run movies and films that never reach the multiplex. Each one keeps its own calendar on its own website.

      7:30 Showtimes reads those calendars and puts every screening on one schedule, so you can see what is playing tonight without opening eight tabs.

      How it works

      A script checks each theater’s public listings every six hours and rebuilds this page. Times are Eastern. Ticket links go straight to the theater.

      Theaters change their schedules, and their websites, without warning. If a time here disagrees with the theater, the theater is right. The Theaters page shows when each one was last read successfully.

      Credits

      Posters, years and synopses come from TMDB. This product uses the TMDB API but is not endorsed or certified by TMDB.

      The code is open: github.com/defrank1/dc-film. Spotted a wrong time or a missing theater? Open an issue.
